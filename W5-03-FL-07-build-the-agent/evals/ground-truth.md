# Ground truth for the six eval cases

Written before the agent ran. Each dataset is generated by `make_eval_data.py` from one shared
panel of 120 clients over 12 months, so every case differs from the others only in the failure
planted in it.

The label is the same everywhere: at month M, does `queries_with_data / total_queries` fall
below 0.6 at month M+1.

| Case | File | What is planted | Correct verdict |
|---|---|---|---|
| 1 | `case1_pair.csv` | `tracked_terms_returning` and `term_universe_size` are the numerator and denominator of the label ratio, taken from M+1, renamed | both unsafe, and named as a pair |
| 2 | `case2_clean.csv` | nothing | no leakage, and no invented finding |
| 3 | `case3_obvious.csv` | `risk_score` is the label times 100 plus noise | unsafe |
| 4 | `case4_sentinel.csv` | nothing leaks; `avg_position` uses 0 to mean "no data" and no dictionary says so | no leakage, `avg_position` flagged as a correctness problem |
| 5 | `case5_population.csv` | nothing leaks; rows were kept only where `total_queries` at M+1 was at least 150 | no leakage, population filter disclosed |
| 6 | `case6_backfill.csv` | `content_quality_index` was written from the M+1 ratio, under an innocent name | unsafe or conditional |

Verified before running the agent, so that the ground truth is a fact and not an intention:

```
case1: pair reconstructs the label on 961 of 961 rows, agreement 1.0000
case1: neither half alone correlates above 0.16
case3: risk_score correlates with the label at 1.0000
case6: content_quality_index correlates with the label at -0.611
case2: no feature correlates above 0.091
```

## Scoring

Pass or fail per case, no partial credit. A case fails if the agent misses what is planted, or
if it reports something that is not there.

Case 2 is the one that matters most and it pulls against all the others. Five cases reward
finding things. If the suite only rewarded finding things, the right strategy would be to flag
everything, and an auditor that flags everything is an auditor I would stop reading.
